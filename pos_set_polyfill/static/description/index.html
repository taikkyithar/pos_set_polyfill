POS Set Methods Polyfill

Legacy Android WebView fix for Odoo 19 Point of Sale
Restores 7 missing JavaScript Set methods so Odoo 19 POS opens reliably on older Android POS terminals - including the Sunmi T2 - instead of failing to load.
Odoo 19.0 Point of Sale Zero configuration LGPL-3

The problem

Odoo 19's Point of Sale frontend uses modern ES2024 Set methods - difference(), intersection(), union(), symmetricDifference(), isSubsetOf(), isSupersetOf() and isDisjointFrom(). These only exist in Chrome / Android WebView 122 and later (early 2024).

Plenty of Android POS terminals in active use - the Sunmi T2 among them - run a locked system image that can't be updated (e.g. Android 7.1.1 with WebView 119). On that hardware, opening a POS session throws a JavaScript error and the register screen never finishes loading, even though the exact same database works fine on a modern computer, phone or tablet.

Uncaught TypeError: currentSet.difference is not a function
// typical console error on WebView < 122 without this fix

What this module does

  • Adds the 7 missing Set.prototype methods back, with the same behaviour as the native implementation.
  • Only defines a method if it's actually missing - on modern browsers every method is left untouched, so it's a true no-op there.
  • Installs methods as non-enumerable, matching native semantics, so it won't leak into for...in, Object.keys() or feature-detection code.
  • Ships as a single plain script appended (not prepended) to the POS production assets bundle, so Odoo's own module loader bootstrap is never disturbed.
  • Runs synchronously as the bundle parses - before POS's own async startup code ever calls a Set method - so there's no race condition.

Who this is for

Retailers, restaurants and implementers running Odoo 19 Point of Sale on older or budget Android terminals - Sunmi devices, generic Android POS boxes, or older tablets - that cannot be upgraded to a newer Android System WebView. It also works as a safety net anywhere the WebView version on POS hardware can't be guaranteed in advance.

Installation

  1. Go to Apps, click Update Apps List, then search for "POS Set Methods Polyfill".
  2. Click Install.
  3. Fully reload the POS session on the affected terminal (close and reopen the POS screen/browser) so it picks up the updated asset bundle.

No further configuration is required.

Frequently asked questions

Will this slow down POS on modern devices?

No. On any browser that already has native Set methods, the polyfill detects that and does nothing.

Does it modify Odoo core files?

No. It only appends one script to the point_of_sale.assets_prod bundle.

Will it conflict with other POS apps I've installed?

It's designed not to - it only adds a method if one doesn't already exist, and it appends to the bundle rather than replacing anything.

Does this fix every issue on old Android POS terminals?

It fixes the specific crash caused by missing ES2024 Set methods. Very old devices can occasionally be missing other modern JavaScript APIs as well, which would need separate polyfills.
